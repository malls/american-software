# AS-103 — live tool-level activity, ephemeral over /api/stream

Planner agent:cto-owen, 2026-09-13. Complexity **medium** (three stages). The description holds the board source
(DM 668), the live-only constraint and the not-in-scope list; this is the *how* only.

## 1. Scope — the minimal implementation

1. **`lib/activity.js`** — one pure module: reduce a harness tool call to a coarse object, derive the lane key
   from a cwd, compose the sentence, hold the constants. No fs, no clock, no process (`lib/lanes.js`'s rule).
2. **`bin/activity-hook.mjs`** — the producer: reads one hook JSON payload on stdin, POSTs `{cwd, tool, object}`,
   **always exits 0, writes nothing to stdout/stderr, self-bounds at 250 ms**, dies silently with no listener.
3. **`POST /api/activity`** — validate, derive the lane, throttle, fan out one `event: activity` frame to the
   open SSE connections. **No store call, no file write, no timer, no replay.**
4. **Client** — `state.activity`, an `activity` listener, the `now:` line.

Out of scope by decision: the `hooks` block in `.claude/settings.json` is metawork-layer plumbing (§6 — the
metawork layer applies it, never an employee); AS-100's persisted stream is untouched; `public/lanes.js`
(`describeActivity`, `ACTIVITY_DECAY_MS`) and `style.css` (`.lane-now--*`) already ship from AS-99, unchanged.

**Deviation from the description, so a reviewer does not read it as an omission:** the frame carries **no employee
field**. Attribution is still derived, never self-reported — the lane key *is* the derivation — and the card
already names the assignee from `/api/lanes`. That keeps a `.lattice` read out of the hot path; AC-7 pins it.

## 2. Approach

**Wire shapes.** Hook → server `{cwd, tool, object}`, `object` already coarse (relative path, first token,
hostname, or null): a full command line, grep pattern or file body never leaves the host process. Server →
browser, exact keys `{key, text, at}`. The hook reduces at the source, the server decides the words and clamps
them — defence in depth, both halves pure and unit-tested.

**Reduction** (`activityText`): Read/Write/Edit → `reading|writing|editing <rel>` (path relative to the cwd;
outside it, basename only — never an absolute host path); Bash → `running <first token>` (basename, ≤24 chars);
Grep/Glob → `searching` (pattern dropped, not clamped); Task → `delegating to <type>`; WebFetch → `fetching
<host>`; **anything else → `using <tool>`**. The table never has to be exhaustive and no unreduced input can
reach a browser. Text clamp 80 chars, control characters and newlines stripped.

**Lane derivation** (`laneKeyFromCwd`): match the path *suffix* `.worktrees/<seg>`, then `AS-\d+` out of `<seg>` —
suffix, not absolute prefix, because the hook runs on the host and the server in a container over a bind mount. A
cwd outside a worktree (the orchestrator, a live metawork session) yields null and the frame is **dropped** (Q2).

**Throttle:** `Map<laneKey, lastSentMs>`; drop — never queue — a frame inside `ACTIVITY_MIN_INTERVAL_MS`
(200 ms): only the freshest frame matters to an animation layer, a dropped one costs nothing, the 15 s decay
covers the tail. **Always 200:** every outcome (delivered, throttled, no-lane, bad-tool) answers
`200 {activity:{accepted, reason, key, delivered}}`, so the hook never retries and the suite can assert the
decision without opening a stream.

## 4. Acceptance criteria

Each names its falsifier; met only by an **observed red** against the named mutant (M4), red sets recorded.

1. A frame with a worktree cwd reaches an open `/api/stream` as `event: activity` with `{key,text,at}`.
   **M1:** delete the fan-out loop → red.
2. **LIVE-ONLY (headline).** Drive 50 frames; sqlite row count, the file set *and sizes* under the server's
   `dataDir`, and the AS-100 stream length are byte-identical before and after. **M2:** add a `store.post` (or
   `appendEvent`) → red.
3. A stream opened *after* those 50 frames gets zero `activity` frames within `FRAME_MS` (its `loop`/`lanes`
   frames still arrive). **M3:** buffer the last frame and replay it on connect → red.
4. `/api/events` and `GET /api/lanes` unchanged across the burst. **M4:** route the frame through
   `tailEvents()` → red.
5. Derivation: host path, container path, nested `.worktrees/AS-7/sub/dir`, main-checkout cwd (→ `no-lane`,
   not delivered). **M5:** absolute prefix instead of suffix → red on the container path.
6. Reduction: one case per table row, unknown tool → `using <tool>`, a 4 KB command → `running <token>` with
   token ≤24 chars, text ≤ `ACTIVITY_TEXT_MAX`, no `\n`/absolute path/raw pattern anywhere. **M6:** return
   `tool_input.command` verbatim → red.
7. The fanned-out payload's key set equals `ACTIVITY_FRAME_KEYS` exactly. **M7:** add an `employee` (or
   `cwd`) key → red.
8. Two frames 50 ms apart on one lane deliver once (`reason: 'throttled'`); on two lanes, twice. **M8:**
   make the throttle global → red on the second.
9. Malformed bodies (`tool` absent / 200 chars / `{}` / `object` numeric) answer 200 with a reason and
   deliver nothing. **M9:** drop the `tool` pattern check → red.
10. `GET /api/activity` 404s and produces no frame. **M10:** accept any method → red.
11. Zero open connections: `delivered: 0`, `accepted: true`, nothing written.
12. **Hook battery** (spawned child, real socket): exact POST body for a fixture PreToolUse payload; exit 0 with
    empty stdout+stderr on success, nothing listening, garbage stdin, empty stdin, 1 MB stdin; wall clock < 1 s
    with nothing listening. **M11:** remove the `.catch()` → red on the no-listener case.
13. `CHAT_ACTIVITY_OFF=1` exits 0 and posts nothing. **M12:** ignore the variable → red.
14. `PostToolUse` and `PreToolUse` fixtures produce the **same** body — the script reads only
    `cwd`/`tool_name`/`tool_input`, which keeps Q1 a settings-only flip.
15. Browser walk (headless CDP, the AS-135 recipe): a posted frame renders `now: reading …` with
    `.lane-now--live`; after `ACTIVITY_DECAY_MS` it reads `--decayed`; a reload leaves it blank and issues no
    request. **M13:** seed `state.activity` from a fetch → red on the reload case.
16. Suite green with a `--build` receipt (`Image … Built`), host and compose counts recorded, leak check clean.
