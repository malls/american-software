# AS-133: Chat tooling: compose-run.mjs signal contract misses SIGHUP (a terminal hang-up mid-run still leaks) and the 'run' argv match can hit argv[0] (AS-121 Priya O3)

Filed under the triage gate from the AS-121 cycle-2 review (qa-priya, 2026-09-12, scratchpad/agent-qa-priya/AS-121/cycle2/). Two residuals in apps/chat/bin/compose-run.mjs's armedExec(): (1) only SIGINT/SIGTERM are armed, so a SIGHUP mid-run (terminal hang-up on a hand-run counted run) kills node by default and the image/network leak AS-121 closed for the other two signals is still reachable; (2) the arming predicate argv.includes('run') also matches argv[0], so a relative ADVANCE_DOCKER_BIN literally named 'run' would arm at 'network ls' — the pre-flight window AS-121 deliberately leaves unarmed. Fix shape: arm SIGHUP alongside the pair; match 'run' only in the subcommand position (argv after the docker bin and the compose args). Falsifiers: a stub-docker SIGHUP test in the T12 family observed red before the fix; an argv[0]='run' test whose pre-fix red is the handler armed at network ls (T12c's shape). Low: tooling-only, hand-run path, fails toward a leak the leak check reports.
