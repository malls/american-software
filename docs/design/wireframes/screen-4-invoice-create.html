S4-ABANDON Abandonment Freelancer leaves the parent invoice form before submitting

What's lost depends on create vs. edit

New, never-saved invoice (/invoices/new): nothing persists — returning starts blank at S4-DEFAULT-CREATE.

Editing an existing draft (/invoices/:id/edit): only the unsaved changes are lost. The draft as it was last explicitly saved still exists and reappears at S4-DEFAULT-EDIT. There is no autosave in v1 — no capability row asks for one.

S4-CLIENT-ABANDON Abandonment Freelancer leaves the nested client form specifically, distinct from S4-ABANDON — shared sub-pattern, 02-states-ledger.md §0

Only the new-client attempt is lost

No client record is created. The invoice form itself (line items, due date) is unaffected by this specifically — see S4-ABANDON for what happens to the invoice draft itself when the whole form is abandoned.
