S5-DENIED-NOTOWNER Permission-denied / gated Signed in as a different freelancer, requests an invoice ID they don't own

Renders identically to "not found"

Deliberate: this state uses the exact same rendering as S5-ERROR-NOTFOUND. Confirming "this ID exists but isn't yours" leaks more than confirming nothing. Listed as its own row because the reason differs even though the rendering doesn't — a reviewer should be able to see that was a choice, not a missed case.
