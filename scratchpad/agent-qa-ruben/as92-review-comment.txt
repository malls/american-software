N2 (record only). Harmless; presence matching is byte-exact by design and normalising would be scope creep.

N3 (record only). PATH === '' with a non-empty prepend yields `/usr/local/bin` rather than `/usr/local/bin:` — the empty original is dropped, not kept as the "untouched suffix" the plan's §2.3 wording promises. This is the SAFER behaviour (an empty PATH entry means the current directory in POSIX lookup), and PATH === '' with an empty prepend still passes '' through byte-for-byte. Deviation from the plan's words only in this degenerate case; no change wanted.
